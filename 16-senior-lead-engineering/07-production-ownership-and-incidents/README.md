# production ownership and incidents

Status: planned.

## Goal

Lead a simulated incident affecting order processing.

## Evidence of completion

- [ ] Triage, mitigate and communicate before attempting a large redesign.
- [ ] Produce a timeline, evidence, recovery verification and blameless postmortem.
- [ ] Assign preventive actions with owners and completion criteria.
- [ ] Document setup, exact run/check commands, and relevant failure cases.
- [ ] Explain an alternative and the cost of the chosen approach.


Keep implementation and evidence in this folder. Create src/, tests/, docs/, or infra/ when needed.
