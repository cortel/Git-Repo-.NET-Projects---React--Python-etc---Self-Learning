# stakeholder communication and estimation

Status: planned.

## Goal

Handle a deadline that conflicts with scope and reliability requirements.

## Evidence of completion

- [ ] Provide an estimate range, assumptions, uncertainty and options.
- [ ] Write an early risk update and negotiate a smaller deliverable.
- [ ] Distinguish an estimate from a commitment and document the agreed acceptance criteria.
- [ ] Document setup, exact run/check commands, and relevant failure cases.
- [ ] Explain an alternative and the cost of the chosen approach.


Keep implementation and evidence in this folder. Create src/, tests/, docs/, or infra/ when needed.
