# mentoring and code review

Status: planned.

## Goal

Improve another developer's ability to reason about and maintain a system.

## Evidence of completion

- [ ] Review a deliberately flawed change with specific actionable comments.
- [ ] Separate correctness and security issues from style preferences.
- [ ] Prepare a pair-programming exercise and feedback tied to observed behavior.
- [ ] Document setup, exact run/check commands, and relevant failure cases.
- [ ] Explain an alternative and the cost of the chosen approach.


Keep implementation and evidence in this folder. Create src/, tests/, docs/, or infra/ when needed.
