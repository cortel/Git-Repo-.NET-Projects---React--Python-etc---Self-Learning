# boundaries and learning tests

Status: planned.

## Goal

Protect a domain feature from a third-party integration.

## Evidence of completion

- [ ] Write small tests exploring the dependency's behavior and failure contracts.
- [ ] Introduce an adapter only at the meaningful boundary.
- [ ] Demonstrate replacing a fake integration without changing domain rules.
- [ ] Document setup, exact run/check commands, and relevant failure cases.
- [ ] Explain an alternative and the cost of the chosen approach.


Keep implementation and evidence in this folder. Create src/, tests/, docs/, or infra/ when needed.
