# professionalism and sustainable practice

Status: planned.

## Goal

Apply professional responsibility to a fictional release under pressure.

## Evidence of completion

- [ ] Make an explicit commitment with assumptions and an escalation trigger.
- [ ] Practice review, pairing and a short deliberate coding exercise.
- [ ] Write a response that protects quality while offering realistic scope choices.
- [ ] Document setup, exact run/check commands, and relevant failure cases.
- [ ] Explain an alternative and the cost of the chosen approach.


Keep implementation and evidence in this folder. Create src/, tests/, docs/, or infra/ when needed.
