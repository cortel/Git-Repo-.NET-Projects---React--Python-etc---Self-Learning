# bdd and acceptance tests

Status: planned.

## Goal

Translate a business scenario into executable acceptance criteria.

## Evidence of completion

- [ ] Write Given/When/Then scenarios with realistic business language.
- [ ] Implement one flow through the API and verify observable results.
- [ ] Distinguish acceptance coverage from unit and contract coverage.
- [ ] Document setup, exact run/check commands, and relevant failure cases.
- [ ] Explain an alternative and the cost of the chosen approach.


Keep implementation and evidence in this folder. Create src/, tests/, docs/, or infra/ when needed.
