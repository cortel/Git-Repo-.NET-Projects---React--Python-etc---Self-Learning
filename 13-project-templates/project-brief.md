## Scope and acceptance criteria
Define observable behavior and relevant failure cases.

## Design
Describe components, data, contracts, alternatives and tradeoffs.

## Setup and run
Record prerequisites, versions, configuration and exact commands. Include example values without secrets.

## Verification
Record tests or manual checks, commands and expected outcomes.

## Operations
When applicable: deployment, rollback, telemetry, costs, backup and restore.

## Lessons
Record a difficult decision, a correction and the next improvement.
