# Inventory and orders with an AI support extension

Status: planned. This is the main code home for the [focused learning path](../../00-roadmap/start-here.md).

Build an application for synthetic inventory and order operations using ASP.NET Core, React/TypeScript, EF Core and PostgreSQL. Keep it as one modular application. Add AI features to this codebase after the business feature works.

## First vertical slice

- [ ] Display stock and create an order through a React form and .NET API.
- [ ] Enforce quantity, stock and order-state invariants with a test-first example.
- [ ] Persist with migrations; test two competing stock reservations.
- [ ] Authorize reads/writes and use consistent validation/error responses.
- [ ] Show loading, empty, error and success states; support keyboard use.
- [ ] Verify a real database integration and one browser-level flow.
- [ ] Run CI and document setup, configuration and exact commands.
- [ ] Diagnose a deliberately slow query and explain one architecture decision.
