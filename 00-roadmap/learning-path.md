# Foundation reference

The active learning order is [Start here](./start-here.md). Use this checklist only when the current project reveals a gap; it is not another course to finish first.

| Gap | Supporting exercise |
| --- | --- |
| Cannot reproduce or explain a Git change | [Git and collaboration](../01-foundations/git-and-collaboration/) |
| C# types, nullability or object behavior are unclear | [C# and OOP](../02-dotnet-backend/csharp-and-oop/) |
| Async work blocks, leaks or loses failures | [Async/cancellation](../02-dotnet-backend/async-concurrency-and-cancellation/) |
| Requests, status codes or network failures are confusing | [HTTP/DNS/TLS](../01-foundations/http-dns-tls-and-networking/) |
| Query behavior or storage choices lack evidence | [SQL/schema design](../05-databases-and-data/sql-and-schema-design/), [query plans](../05-databases-and-data/indexes-and-query-plans/) |
| Frontend state or data flow is difficult to reason about | [React state](../03-react-frontend/hooks-state-and-effects/), [server data](../03-react-frontend/api-and-server-state/) |
| Tests mirror code without catching failures | [TDD](../08-testing-and-quality/tdd-red-green-refactor/), [integration tests](../08-testing-and-quality/integration-tests/) |
| Business rules are unclear or scattered | [DDD discovery](../10-architecture-and-system-design/domain-driven-design/01-domain-discovery-and-language/) |
| An abstraction makes changes harder | [Refactoring](../17-clean-code-and-craftsmanship/04-refactoring-and-code-smells/), [pattern selection](../04-design-patterns/pattern-selection-and-principles/) |

Start pattern practice with Strategy, Factory Method, Adapter, Decorator, Observer or Command when the feature supplies a useful example. All [23 classic pattern folders](../02-dotnet-backend/design-patterns/) remain available; completing all of them is optional depth.

Return to the active feature after fixing the gap. Record a runnable demonstration or measurable result in [progress](./progress.md).
