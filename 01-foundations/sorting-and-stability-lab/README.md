# sorting and stability lab

Status: planned.

## Goal

Compare comparison-based sorting with a bounded-integer counting sort.

## Evidence of completion

- [ ] Implement insertion, merge, quick and heap sort; optionally extend to introsort/radix.
- [ ] Verify duplicate-key stability, empty inputs, adversarial distributions and output correctness.
- [ ] State time and auxiliary-space assumptions; compare Array.Sort, List.Sort and LINQ OrderBy.
- [ ] Document setup, exact run/check commands, and relevant failure cases.
- [ ] Explain an alternative and the cost of the chosen approach.


Keep implementation and evidence in this folder. Create src/, tests/, docs/, or infra/ when needed.
